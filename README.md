# War-Thunder-Mod-Organizer
This is the War Thunder Mod Organizer, and a part of the U.M.O. project.

Special thanks to the Reddit python community and GTG Discord team. This would not have been possible without your help!

RELEASE VERSION 1.0:
On the repository you can view the code and artwork for the project as desired.

Please refer to the "Releases" tab on the right hand side of the repository if you wish to download the full program. (See Install Instructions Below)

Currently supports: WINDOWS
To be supported: MacOS, Linux

Thank you for visiting and I hope this project helps you in all your future modding endeavors.

INSTALLATION:

1) Navigate to the Releases tab on the right hand side of this GitHub page and left click on " WTMO-Release-1-ZIP-File " 
(or click this link: https://github.com/RuseTiger/War-Thunder-Mod-Organizer )

2) A new page will open and you will see 3 files in the middle of your screen: WTMO-Release-1.zip, source code (zip) and source code (tar), left click on "WTMO-Release-1.zip"

   2.1) A popup may appear asking where you would like to save the .zip file, on the left of this popup you will have options such as: Desktop, Downloads, Documents, etc
        Please select "downloads" and then click save in the bottom right of the popup.

3) The program will now begin downloading, the file is 665-MB so this can take a few minutes (two large files which are the .exe and .pkg take up ~600-mb of the 665-MB total.)

4) Once your download finishes, open your file browser and then to "downloads", you will see a zip file in your downloads named "WTMO-Release-1", you can leave it in your downloads
   page or drag it to your desktop or another location of your choosing. Once you choose where you wish to leave the .zip; please right click on the .zip file.

5) You will now see a popup with a list of options, look for "Extract All" and left click, then a second popup will appear, please click ensure there is a checkmark in the check box that     says "Show Extracted Files When Complete" as this will automatically open the new program folder when it is done, please left click on "Extract" at the bottom of the popup.

   5.1) Your file will now extract, this may take a minute, when it finishes you will have a new folder with the name "WTMO-Release-1"

6) Now that you have a new folder named WTMO-Release-1, if you had a checkmark in the checkbox you will see the program folder has already opened, if you do not see the folder already open, you can double left click on the new folder to open it and you will see the program's contents, We want to find the "dist" folder and double left click on it, inside will be our WTMO.exe file

   6.1) While in the program folder, feel free to view the images or open the .py code file which holds the source code if you'd like to read through it.

   6.2) While you are looking at the WTMO.exe file, feel free to right click it and then left click "Pin to Start"/"Create Shortcut" if you'd like to be able to launch WTMO from your
         windows start tab or if you'd like to drag and drop a shortcut onto your desktop or if either option is missing, left click on "Show More Options" and you should see them in the           larger list.

7) Please double left click on the WTMO.exe file

8) The War Thunder Mod Organizer will now open, please left click on the "Root Folder" button in the top left-hand side of the application window and follow the onscreen prompts for setting up the organizer.

9) Thank you for your time and I hope you enjoy the Mod Organizer!

10) NOTE IF WINDOWS DEFENDER GIVES AND ERROR/RED FLAG:
Please click on "More Info" and "Run Anyway" this is Windows trying to protect your PC from malicious programs but windows defender can't actually go in depth and check every file you download so it raises the red flag whenever there could be danger to make sure users are paying attention and not just downloading tons or random programs. It's a good thing to see this flag, it means windows is doing its job, the flag should not appear in the future though after you run the program for the first time windows tends to relax. Additionally if anyone is big on checking code, the code is packaged with the Mod Organizer for a reason.
