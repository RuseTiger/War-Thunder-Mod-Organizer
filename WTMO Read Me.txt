Hello everyone!

This is the War Thunder Mod Organizer, an example variant of the Universal Mod Organizer project.

Special thanks to the Reddit python community and GTG Discord team. This would not have been possible without your help!

- Note this is a release version of the mod organizer - HOWEVER:
- Current version needs proof reading and major critics as well
- as a mod deploy and retract code block/ui elements which still

Thank you for downloading and have fun!

If you have any issues to report, please feel free to make a post on GitHub:
https://github.com/RuseTigerDev/War-Thunder-Mod-Organizer/issues
